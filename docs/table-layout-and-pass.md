# 卓レイアウト調整と自動ツモ切りの見逃し

対象: `174bf6b` 時点からの修正
状態: **実装済み**

## 1. 自動ツモ切り中の和了形・カンの見逃し

- 課題: 自動ツモ切り中に和了形・カン可能になると必ず停止する。欲しい牌の目標に達していないときは続けたい場合がある。
- 対応: 設定「自動」タブの欲しい牌エディタの下に「目標に達する前に」として2つのチェックを追加（既定 OFF＝従来どおり停止）。
  - `adPassWin`: 和了形になっても止まらずに続ける（見逃してツモ切り）
  - `adPassKan`: カンできても止まらずに続ける（カンせずに打牌）
- 優先順位（`ui.js` `afterDraw`）
  1. 卓の「自動和了」「自動カン」が ON ならそちらを実行
  2. 和了・カンできて、対応する見逃しが OFF なら停止
  3. それ以外は `autoDiscardTarget()`。目標達成ならここで停止するので、目標を満たした状態では和了・カンできる手で止まる
- 条件を何も選んでいない（常にツモ切り）場合も、見逃しが ON なら和了形・カンを見逃して続ける。
- 見逃した和了は記録に「自動ツモ切り 和了形を見逃し」と残す。
- リーチ中の「リーチ後は自動でツモ切り」（操作タブ）は従来どおり和了・カンで停止。自動ツモ切りボタンが ON のときだけ見逃し設定が効く。

## 2. 向聴表示とリーチ棒の間隔

- 原因: 状態表示の行（`.status-row`）の高さが、2行に積んだ自動和了／自動カンのトグルと卓右上の待ち表示で決まり、向聴表示の下に大きな空白ができていた。
- 対応:
  - トグルを横1行に並べ、行の高さを向聴表示とほぼ同じにした（トグルは行の左列に残るので河とは重ならない）。
  - 待ち表示を卓の外へ移した（下記3）。
  - 卓の縦 `gap` を 14px → 4px、上 padding を 18px → 14px に。リーチ棒の分の余白（`.river-wrap` の padding-top）は 14px。
- 結果: 向聴表示の下端からリーチ棒まで約 8px。スマホ横向き（3列レイアウト）は従来どおり。

## 3. 待ちを右パネルへ、記録は折りたたみ

- 課題: 多面待ちのとき卓右上の待ち表示が縦に伸び、河の領域を圧迫していた。
- 対応:
  - 右パネルを「牌効率 → 待ち → 記録」の順にし、以前の記録の場所（残りの高さ）を待ちに使う。聴牌でないときは案内文を出し、パネルの高さは変えない（レイアウトが跳ねない）。
  - 記録は `<details>` で折りたたみ（既定は閉じる。開閉状態は `localStorage` の `soloMahjong.logOpen` に記憶）。開いたときは最大 30vh でスクロール。
  - スマホ横向き（`(orientation: landscape) and (max-height: 500px)`）は右パネルを出さないため、`matchMedia` で判定して待ち表示の要素を卓の右上（`#status-row`）へ移す（`placeWaitsBox`）。この場合は従来どおり聴牌時のみ表示。
