# 牌画像

出典: [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles)（Regular）
ライセンス: パブリックドメイン（[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)）

牌面の図柄のみ（背景透過）。牌の地・影は CSS で描画する。
ファイル名は牌コード（`1m`〜`9m` / `1p`〜 / `1s`〜 / `1z`〜`7z` = 東南西北白發中、`0m` `0p` `0s` = 赤5）。
取り込み時に Inkscape のメタデータを除去し、ファイル名を変更した。風牌（`1z`〜`4z`）の文字色は紺（#142896 / #19328c）から黒（#1c1c1c）に変更した。
