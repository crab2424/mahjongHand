# 一人麻雀 — ツモ切りシミュレーター

麻雀牌を用いて配牌をガチャ感覚で引き，1人でツモって牌を捨てるシミュレーション麻雀ゲーム。
ブラウザだけで動作します（サーバー不要・画像素材なし）。

## 起動方法

`index.html` をブラウザで開くだけです（ダブルクリック / ドラッグ＆ドロップ）。
Node や Python は不要です。

任意でローカルサーバーから配信しても動きます。

```bash
python3 -m http.server 8000
```

## 遊び方

1. 起動すると配牌13枚＋第一ツモの14枚が配られます（天和・ダブルリーチの判定がすぐにできます）。
2. 手牌の牌をクリックすると河に捨て，次の牌をツモります（設定で手動ツモに変更可）。山が尽きるかツモ回数の上限に達するまで続きます。
3. 聴牌していれば **リーチ**，4枚揃っていれば **カン**（暗槓），和了形なら **ツモ和了** ボタンが出ます。
4. 和了すると役・符・飜・点数を表示します。山が尽きると荒牌流局（聴牌/ノーテン判定）。
5. **配牌リセット**（または `N` キー）でいつでも新しい配牌に。

### 画面の情報

- ヘッダー: 場風・自風，ドラ表示牌（カンで増える），残りツモ回数（山の枚数），巡目
- 卓中央: 向聴数，河（ツモ切りは暗め・リーチ宣言牌は横向き）
- 卓右上: 聴牌中は待ち牌と残り枚数を常に表示（リーチ中も継続）
- 右パネル: 牌効率（打牌候補ごとの受け入れ枚数）と記録
- 手牌: 打牌候補の上に受け入れ枚数のバッジ（最多は橙）

### 配牌リセット・自動リセット

- **配牌リセット**（`N`）: 新しい配牌に。設定「簡略化」でアニメーションを省き即時に切り替えられます。
- **自動リセット**（`A` または「▶ 自動リセット」ボタン）: 条件を満たす配牌が出るまで自動で配り直します。天和・ダブルリーチ狙いの機能です。
  - 実行間隔: 「10秒ごとに1回」〜「1秒に1000回（最速）」。1秒に2回以上の高速時はアニメーションを省略し表示を間引きます。
  - 停止条件: 14枚の向聴数が「和了形（天和）／聴牌以下／一向聴以下／…」になったら停止し，その配牌で遊べます。
  - `Esc` またはボタンで途中停止。

### 設定（⚙）

| 項目 | 内容 |
| --- | --- |
| 牌の表示 | 麻雀牌の文字（🀇🀙🀐）／ 数字＋文字（5萬 / 東） |
| 場風・自風 | 役牌・点数計算（親/子）に反映 |
| 自動ツモ | 打牌後に自動でツモる |
| リーチ後は自動でツモ切り | 和了・カンが無い場合に自動でツモ切り |
| 打牌は2回クリックで確定 | 誤操作防止 |
| 簡略化 | 配牌リセットのアニメーションを省略 |
| 自動リセット | 上記。実行間隔と停止条件（向聴数）を指定 |
| 赤ドラ | 赤5 各色1枚（次の配牌から） |
| 山に入れる牌 | 萬子・筒子・索子それぞれ「一九」「二〜八」，字牌の7グループを選択（三麻は「萬子 二〜八」を外す）。最低40枚（次の配牌から） |
| ツモ回数の上限 | なし／27／18（実戦相当）／12／9 回（次の配牌から） |
| 他家のツモを模擬 | 1巡ごとに山が4枚減り，約28巡で流局（次の配牌から） |

設定は `localStorage` に保存されます（自動リセットの ON/OFF は起動時に常に OFF）。

## 採用ルール

- 136枚（赤ドラは任意），王牌14枚，ドラ表示牌は王牌の所定位置。暗槓で即時カンドラ・海底牌が王牌へ。
- 牌種を絞った場合（三麻など），ドラは山に無い牌種を飛ばして順送り（1m 表示 → 9m）。受け入れ・待ちにも山に無い牌種は含めない。
- ツモ回数の上限を設定した場合，上限最後のツモが海底牌扱い。
- 門前ツモのみ（他家がいないためロン・鳴きなし）。暗槓は可，リーチ後は待ちが変わらない場合のみ。
- 役: 一般役すべて（立直/ダブル立直/一発/門前清自摸和/断幺九/平和/一盃口/役牌/三色同順/一気通貫/三暗刻/三色同刻/三槓子/混老頭/小三元/混全帯幺九/純全帯幺九/二盃口/混一色/清一色/七対子/海底摸月/嶺上開花）
- 役満: 天和/国士無双(十三面は2倍)/四暗刻(単騎は2倍)/大三元/小四喜/大四喜(2倍)/字一色/清老頭/緑一色/九蓮宝燈(純正は2倍)/四槓子，数え役満あり
- 符計算: 副底20＋ツモ2，平和ツモ20符，七対子25符，連風牌雀頭4符。切り上げ満貫なし。
- 点数: 親は「◯オール」，子は「子-親」で表示（ツモ和了）。

## ファイル構成

```
index.html        画面構造
css/style.css     見た目・アニメーション（牌サイズは画面幅に連動）
js/tiles.js       牌定義・山生成・ユーティリティ
js/shanten.js     向聴数・待ち・受け入れ解析・面子分解
js/yaku.js        役判定・符・点数
js/game.js        ゲーム進行（配牌/ツモ/打牌/リーチ/カン/和了/流局）
js/ui.js          描画・アニメーション・操作
js/main.js        起動
tests/test.js     ロジックの検証（node tests/test.js）
```

`file://` で開けるよう，ES modules ではなく通常の `<script>` を順に読み込む構成です。

## テスト

```bash
node tests/test.js
```

向聴数・待ち・受け入れ・役判定・点数・進行を検証します（ブラウザ実行には不要）。
